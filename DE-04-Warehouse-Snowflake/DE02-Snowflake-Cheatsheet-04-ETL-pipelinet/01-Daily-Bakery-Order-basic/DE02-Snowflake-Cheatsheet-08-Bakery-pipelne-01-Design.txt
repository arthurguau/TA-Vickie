# 01. cost insight
Admin -> Cost management -> Account Overview -> Cost insights

- Rarely used tables with automatic clustering
- Rarely used materialized views
- Rarely used search optimization paths
- Large tables that are never queried
- Tables over 100 GB from which data is written but not read
- Short-lived permanent tables
- Inefficient usage of multi-cluster warehouses


# 02. Optimizing cloud services for cost

- Copy commands with poor selectivity
- High-frequency DDL operations and cloning
- High-frequency, simple queries
- High-frequency INFORMATION_SCHEMA queries
- High-frequency SHOW commands (by data applications and third-party tools)
- Single-row inserts and fragmented schemas (by data applications)
- Complex SQL queries
