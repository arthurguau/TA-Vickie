# concept: Tabular UDFs, also known as UDTFs, 
require stateful operations to be performed on data batches and are invoked once per row, 
just like scalar UDFs, but they can return multiple rows as output for each input row. 

The UDTF handler method consists of an additional optional parameter that 
helps initialize the handler once for each partition and finalize processing for each section. 
A UDTF is a type of UDF that executes similarly to a UDF but with tabular output.

# 01. define function
class CalculateAverage:
    def __init__(self) :
        self._values = []
    def process(self, input_measure: int) :
        self._values.append(input_measure)
    def end_partition(self) :
        values_list = self._values
        average = sum(values_list) / len(values_list)
        yield(average ,)
